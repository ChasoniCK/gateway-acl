# Переделка интерфейса панели: минималистичный apple-like

Дата: 2026-08-26. Статус: согласовано, план реализации пишется отдельно.

## Зачем

Панель работает и читается, но выглядит админкой: заголовки капсом с трекингом,
моноширинный шрифт на каждом числе, приглушённая полуслучайная палитра, кнопки-контуры,
таблица на шесть колонок с четырьмя контролами в последней. Требуется вид Настроек macOS —
сгруппированные панели, тонкие разделители, один акцентный цвет, системная типографика.

Переделка затрагивает только слой представления: `CSS`, `HEAD`, `LOGIN_T`, `PAGE_T` и
JS-рендеры внутри `PAGE_T`. Ни `ruleset()`, ни учёт трафика, ни `check_settings()`, ни
установщик, ни конвертер подписки не меняются.

## Принятые решения

| Вопрос | Решение |
|---|---|
| Глубина | Полный пересмотр интерфейса: можно убирать и добавлять элементы, менять сценарии |
| Референс | Настройки macOS |
| Темы | Авто по системе + ручной переключатель Авто/Светлая/Тёмная, выбор в localStorage |
| Список устройств | Строка списка с переключателем справа, редкие действия — в раскрытии строки |
| Навигация | Одна лента без вкладок и сайдбара; настройки — отдельный шит |
| Цифры | Системный шрифт с `font-variant-numeric: tabular-nums`; моноширинный только IP, MAC, версия |
| Палитра | Системные цвета Apple, свои значения для светлой и тёмной |
| Основной экран | Десктоп; телефон обязан работать, но плотность считается от десктопа |
| График | Стиль Аккумулятора/Здоровья: скруглённые столбцы, почти нет сетки, карточка при наведении |
| Порядок работы | Снизу вверх, по блокам: сначала токены и примитивы, потом блоки по одному |

## Фундамент

### Токены

`CSS` перестаёт быть списком переменных цвета и становится полным набором: цвет, радиус,
тень, шаг сетки, шкала кегля. Ни одного литерала вне переменных — правило распространяется
и на радиусы с отступами, не только на цвет.

Наборы объявляются четыре раза, и это осознанное усложнение нынешних двух:

- `:root` — светлая, значения по умолчанию;
- `@media (prefers-color-scheme: dark)` — тёмная для тех, кто ничего не выбирал;
- `:root[data-theme="dark"]` — ручной выбор тёмной;
- `:root[data-theme="light"]` — ручной выбор светлой, обязан перебивать media-запрос.

### Цвет

| Роль | Светлая | Тёмная |
|---|---|---|
| фон окна | `#F2F2F7` | `#1C1C1E` |
| панель | `#FFFFFF` | `#2C2C2E` |
| разделитель | `rgba(60,60,67,.29)` | `rgba(84,84,88,.6)` |
| текст | `#000000` | `#FFFFFF` |
| вторичный текст | `rgba(60,60,67,.6)` | `rgba(235,235,245,.6)` |
| акцент (blue) | `#007AFF` | `#0A84FF` |
| активность (green) | `#34C759` | `#30D158` |
| опасное (red) | `#FF3B30` | `#FF453A` |
| исходящий (orange) | `#FF9500` | `#FF9F0A` |

Синий — единственный акцент: переключатели, ссылки, выбранное, входящий трафик в графике.
Зелёный означает ровно одно — «устройство активно сейчас». Красный — «удалить» и открытый
байпас. Оранжевый — исходящий трафик. Других цветов на странице нет.

### Типографика

Системный стек. Шкала:

- 20/600 — заголовок страницы;
- 13/600 обычным регистром — заголовок группы; **капс с трекингом уходит**, это главный
  признак админки в нынешней панели;
- 14 — строка списка;
- 12 — вторичная строка под ней;
- 28/600 с `tabular-nums` — главное число трафика.

Моноширинный шрифт остаётся только там, где несёт смысл: IP, MAC, номер версии.

### Форма

Радиусы: 10 — панель, 6 — контрол, pill — сегмент и переключатель. Теней почти нет:
панели плоские, белое на сером отделяется само. Тень только у шита настроек и у карточки,
всплывающей над графиком. Рамка у панели — только в тёмной теме, волосяная.

### Примитивы

Классы в `CSS`, не компоненты — фреймворка в проекте нет и не будет:

- `.panel` — сгруппированная панель;
- `.list` / `.row` — строка с разделителем, отступленным от левого края под контент;
- `.btn` в трёх видах: обычная, tinted, деструктивная;
- `.field` — поле ввода;
- `.sw` — существующий переключатель, перекрашенный в синий;
- `.seg` — сегментный контрол;
- `.sheet` — модальное окно настроек;
- `.pop` — всплывающая карточка (график, подсказки ⓘ).

Состояния: `:hover` — едва заметная подложка, `:focus-visible` — синее кольцо 2px.

## Шапка и баннеры

Шапка: слева заголовок 20/600, справа текстовые кнопки без рамок — «Настройки», «Выйти».
При прокрутке шапка липнет, под ней появляется волосяной разделитель.

Из шапки уходят три элемента:

- **`msel`, выбор месяца** — удаляется. Он дублирует полосу месяцев внизу карточки трафика,
  и полоса остаётся единственным способом выбрать месяц.
- **CSV** — переезжает в заголовок карточки трафика: это действие над трафиком, не над панелью.
- **Байпас** — переезжает в шит настроек, потому что это редкое и опасное действие.

Появляется **слот баннеров** сразу под шапкой, до трёх строк одна над другой. Каждая:
подложка 10% от роли, текст, действие справа.

| Цвет | Когда | Текст и действие |
|---|---|---|
| красный | `bypass > now` | «Шлюз открыт для всех, осталось 12 мин» + «Закрыть» |
| синий | `S.update` | «Доступна версия 1.5.0» + «Обновить» + ссылка на релизы |
| серый | нет связи | «Нет связи со шлюзом, последний ответ в 14:32» |

Красный баннер заменяет нынешнюю кнопку в шапке: состояние, в котором вся программа
выключена, не должно выглядеть как кнопка. Синий заменяет карточку `#upd`, серый — `#off`.

## Настройки

Поповер из `<details class=gear>` с сеткой из десяти полей заменяется шитом: затемнение,
панель по центру, закрытие по `Esc` и клику мимо. Внутри — группы строк, подпись слева,
контрол справа, подсказка серой строкой под своей настройкой (а не абзацем внизу карточки).

- **Основное** — язык, тема (Авто/Светлая/Тёмная), период опроса, хранить месяцев
- **Сеть** — порт, интерфейс, подсеть, адрес шлюза
- **Обслуживание** — перезагрузка в HH:MM (переключатель и время), проверять обновления,
  уведомлять о них, «Пустить всех» с выбором срока
- **Пароль** — одно поле
- Подвал: `gateway-acl <VERSION>` слева; «Проверить», «Перезагрузить» (красная), «Сохранить»
  справа

Тема хранится в localStorage и не является полем формы настроек — правило шести мест
из CLAUDE.md к ней не применяется, `check_settings()` и `config.json` не трогаются.

## Карточка трафика

Заголовок — имя месяца: «Август 2026» вместо «РАСХОД ЗА МЕСЯЦ». Месяц теперь выбирается
полосой внизу, и надо видеть, какой выбран. Имя получает браузер через
`toLocaleDateString` с языком панели — новых строк в `STRINGS` не требуется. Выбранное
устройство приписывается туда же: «Август 2026 · Ноутбук ×».

Справа в заголовке: сегментный контрол «По дням / За сутки» и текстовая кнопка «CSV».

Пять KPI-плиток схлопываются в две строки:

```
240,85 ГБ  +14%
↓ 208,96 · ↑ 28,49 · 7,77 ГБ в день · прочее 3,40 ⓘ
```

Главное число 28/600 tabular, вторая строка 13 вторичным. «Прочее» появляется только когда
оно есть; ⓘ занимает место нынешнего кружка с вопросом и использует тот же CSS-механизм
подсказки (нативный `title` не годится: карточка перерисовывается на каждом опросе, и
браузер снимает незакрытую подсказку).

### График

- Скруглённые сверху столбцы, стопка сохраняется: входящий синий, исходящий оранжевый,
  прочее серый.
- Сетка уходит вся, кроме одной волосяной линии максимума с мелкой подписью над левым краем.
- Подписи дат по краям и каждые пять, как сейчас.
- Наведение или касание: карточка `.pop` над столбцом с датой и тремя числами, остальные
  столбцы гаснут до 40%. Легенда уходит — цвета подписаны в карточке.
- `<title>` внутри SVG остаётся ради читалок с экрана и клавиатуры.
- Накопительный пунктир остаётся, тоньше, по-прежнему только в режиме «по дням».

### Полоса месяцев

Скруглённые столбики, выбранный синий и с жирной подписью. Добавляется год: сейчас «12»
слева и «08» справа относятся к разным годам, и по панели этого не видно.

## Машина

Список строк: подпись слева, значение справа, разделители. Полоски-метры остаются только
там, где есть настоящий потолок — процессор, память, подкачка, диск.

У нагрузки и температуры метр убирается: он масштабирован формулой, выбранной в коде
(`(temp - 30) / 50`), и притворяется шкалой, которой нет. Остаётся значение и ⓘ с именем
датчика.

## Устройства

### Свёрнутая строка (~48px, кликается целиком)

```
● Ноутбук                                    100,01 ГБ   ⌄  ●━━
  192.168.1.42 · Вы · сейчас             ↓ 7,3 МБ/с ↑ 596 КБ/с
```

- Слева имя (14), редактируется по клику; поле без рамки до наведения.
- Вторичная строка: адрес моноширинным, «Вы» для собственного устройства, время последней
  активности.
- Точка слева зелёная, пока устройство активно, и невидимая, но занимающая место, когда
  нет — колонка не должна прыгать.
- Справа месячный трафик, под ним текущая скорость.
- С краю переключатель, синий, вместо кнопки «выключить». Шеврон между трафиком и
  переключателем поворачивается при раскрытии.

Мобильный хак `thead{display:none}` с перекладыванием ячеек удаляется: строка одинаковая на
любом экране.

### Раскрытие (клик по строке, не по переключателю)

Спарклайн во всю ширину строки, MAC и вендор, таймер сегментами (15 мин / 1 ч / 3 ч / 8 ч /
до утра, либо активное «ещё 2 ч ×»), переключатель «Мимо VPN» при `S.vpnable`, кнопка
«Показать в графике» (нынешний клик по IP, `pickDev`) и «Удалить» красным текстом.

### Заголовок блока

«Устройства»; справа поле поиска в маковском стиле (`/` по-прежнему фокусирует), меню
сортировки текстовой кнопкой («Адрес ↑» вместо кликов по заголовкам колонок; выбор так же
переживает перезагрузку через localStorage), «Выключить всех» с нынешним подтверждением.

### Добавление

Последняя строка списка «+ Добавить устройство», раскрывается в те же два поля с
автодополнением из ARP и DHCP-аренд. Абзац про ручную настройку шлюза, маски и DNS остаётся
под панелью вторичным текстом.

## Чужаки, конфликты, вход

Чужаки и конфликты — такие же списки: адрес слева, под ним имя, MAC и вендор, справа время
последнего стука и кнопка «Добавить» синим. У конфликта — красная ⓘ с нынешним объяснением.

Вход: панель 340px по центру, название, поле пароля, синяя кнопка во всю ширину, ошибка
красным под полем.

## Риски

1. **Раскрытая строка и опрос.** `draw()` перерисовывает `tb.innerHTML` целиком каждые пять
   секунд. Нынешняя защита — не грузить, пока фокус в `INPUT`/`SELECT` — раскрытую строку не
   покрывает, и та будет схлопываться сама. Раскрытый адрес держится в переменной рядом с
   `sel` и восстанавливается после перерисовки. Это главный риск переделки.
2. **Список id в `selftest()`.** Единственная защита от переименования, которое молча
   оставит пустую карточку. Уходят `msel`, `upd`, `bday`/`bhour` в нынешнем виде,
   `h_ip`…`h_seen`, `cumlbl`, `othlbl`, `off`; приходят слот баннеров, шит, переключатель
   темы. Список правится в конце соответствующего этапа, не по ходу.
3. **`STRINGS`.** Новые ключи (тема, сортировка, «Показать в графике», «Экспорт CSV»,
   «Добавить устройство») добавляются в обе таблицы — селфтест сверяет наборы ключей.
   `colAddr`, `colName`, `colSeen` остаются, несмотря на исчезновение заголовков колонок:
   их использует выгрузка CSV.
4. **Тема без мигания.** Одна строка в `<head>`, читающая localStorage и ставящая
   `data-theme` до первой отрисовки.
5. **`theme-color`.** Обе меты остаются захардкоженными (переменную они читать не умеют) и
   при ручном выборе темы разойдутся с панелью. Цена — цвет адресной строки, ничего больше.
6. **Правило шести мест не задевается.** Тема живёт в localStorage; `bypass` и `vpn_mark`
   как были, не поля формы. `check_settings()` не трогается.

## Как смотреть на результат

Панель без root не поднимается, а `--dump` про вёрстку ничего не говорит. На время работы —
одноразовый скрипт в скретчпаде: отдаёт `render(PAGE_T)` и заглушку `/api` с выдуманными
устройствами и месяцем истории. В репозиторий не идёт.

Обязательные проверки на каждом этапе:

```
python3 panel.py --selftest
python3 panel.py --version
```

## Этапы

По коммиту на этап, `--selftest` зелёный на каждом:

1. токены и примитивы в `CSS`;
2. тема: `data-theme`, переключатель, антимигание;
3. шапка, слот баннеров, шит настроек;
4. карточка трафика: KPI, график, полоса месяцев;
5. машина;
6. устройства: строка, раскрытие, сортировка, поиск, добавление;
7. чужаки, конфликты, вход;
8. скриншоты `docs/panel-ru.png` и `docs/panel-en.png`, README.md и README.ru.md, правка в
   CLAUDE.md — переменных больше не «два набора», а четыре;
9. бамп `VERSION` и тег.
